หน้าแรก ปัญหา ตัวอย่างโค้ด เมนู ผู้จัดทำ

ตัวอย่างโค้ดในระบบ

การสร้าง Flask App

from flask import Flask
app = Flask(__name__)

ใช้สำหรับสร้างเว็บแอปด้วย Flask

การสร้าง Route

@app.route("/")
def home():
    return render_template("index.html")

กำหนดเส้นทาง URL ให้แสดงผลหน้าเว็บ

การรันแอป

if __name__ == "__main__":
    app.run(debug=True)

ใช้สำหรับรันเว็บเซิร์ฟเวอร์ในโหมดพัฒนา
